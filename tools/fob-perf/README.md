# Fob CPU 和内存试采

这是待验证测试包，Windows 实测尚未完成

独立只读工具，不安装、不需要管理员、不改 Fob 或系统设置、不联网上传，不需要安装依赖

## 先试采约 90 秒

1. 解压压缩包，在包含 `fob-perf.exe` 的文件夹打开 PowerShell 或终端
   不要双击 exe，命令行窗口可能立即关闭
   若 Windows 安全提示阻止运行，保留提示供核对，不关闭安全功能
2. 保持 Fob 正在运行，只留一个实例，记录当前显示状态和设置，不必为了采样修改设置
3. 检查进程范围：

   ```powershell
   .\fob-perf.exe --help
   .\fob-perf.exe smoke
   ```

   计入列表只包含 `fob.exe` 和能确认父子关系的 `msedgewebview2.exe`
   传感器助手单独列为排除，其他程序的 WebView 不计入
   最后一行必须是「可以开始采样」；有读取失败就先停止，不需要改用管理员运行
4. 读出 Fob 设置中的实际刷新间隔，换算成毫秒，例如 1 秒填 1000，不要照抄别人的数值
   在同一 PowerShell 窗口执行：

   ```powershell
   $refresh = [uint32](Read-Host 'Fob 实际刷新间隔，毫秒')
   $mode = Read-Host '当前状态，tray / mini / statusbar / processes'
   $helper = Read-Host '助手状态和版本，例如 installed-0.8.2 或 disabled，不清楚填 unknown'
   .\fob-perf.exe sample --out .\runs\pilot-01 --label B --app-version 0.8.2 --mode $mode --refresh-ms $refresh --helper $helper --settle-s 30 --steady-s 60
   ```

   `tray` 是只在托盘，`mini` 是迷你窗口，`statusbar` 是状态栏，`processes` 是主窗口进程页
   版本 0.8.2 也是声明值，运行其他版本时替换成实际版本
   其他影响负载的设置可以追加 `--setting '键=值'`，每个键只填一次
   工具不自动读取或验证界面、刷新间隔、版本号和助手状态，不能用错误声明做对比
   采样期间保持界面和工作负载不变，不扫盘、不更新、不启动另一个 Fob
5. 完成后查看 `runs\pilot-01\summary.txt`，保留整个 `pilot-01` 文件夹供核对
   它还包含原始数据、逐进程数据、逐间隔数据和工具自身开销
   已存在的结果目录不会覆盖，再次运行请改成 `pilot-02`

这次只需一个短试采，不安排整轮长时 A/B
按 Ctrl+C 会中止，未完成的目录不是完整结果
若试采显示「有缺失」或「无效」，试采命令会返回非零退出码，但已生成的报告仍可用于排查

## 数字的含义和限制

- 范围只包括 Fob 主进程和沿活着的 WebView 父链确认的 WebView 子进程，不包括任意其他子程序
- CPU 用每个进程两次累计 CPU 时间之差，除以该进程两次读取之间的单调时间，再除以全部逻辑处理器数，最后合计；平均值按采样间隔时间加权
- 采样不是原子快照，逐进程读取有微小时间差；读取偏离采样起点超过间隔的 5%、迟到、缺少请求时长、进程成员变化都会影响完整性
- 第一次读取只建立基线，没有 CPU 百分比；新子进程也要先建立基线，不根据系统时钟猜测它的整段 CPU
- CPU 最高值和 P95 是采样间隔统计，不是瞬时峰值；Windows 任务管理器的 CPU 口径可能不同
- 内存主要看私有提交内存 PrivateUsage，单位 MB 实际为 1024² 字节；它不是任务管理器默认的活动专用工作集
- 工作集合计含共享页，可能重复计算；内存平均值是采样点平均值，趋势是拟合值，短时斜率不能证明内存泄漏
- 等待段和稳定段分开统计，附加前的启动内存峰值无法补测
- 读不到不会当成 0；Fob 退出、重启、进程号复用、发现失败都会使结果失去对比资格
- 传感器助手和 MFT 助手的 CPU、内存明确排除；这不是 Fob 全部配套程序的总开销
- `sampler.json` 和摘要单独记录采样工具自身 CPU 秒数及峰值工作集，不计入 Fob，包含附加、文件哈希和采样，到报告生成前为止；实际开销尚待 Windows 试采确认
- 工具不测唤醒、GPU、硬盘读写；快照之间启动又退出的进程、父进程已退出的孤立 WebView 可能无法归属，「完整」只表示已观察数据符合检查，不保证观察到所有短命进程
- 只导出本次计入或明确排除的进程名、计数器、声明设置和元数据，不导出命令行、环境变量或应用文档；机器名和处理器标识只用于本地哈希指纹，不原文导出
- 会读取 Fob 可执行文件来计算磁盘文件的大小和 SHA256，开始和结束不一致就取消哈希资格；这不是对已加载内存映像或应用版本资源的验证

## 以后再做 A/B

```powershell

```

对比从原始数据重算并核对摘要，拒绝重复、损坏、机器或设置不兼容、同一标签混用版本或哈希的数据
每个状态分别检查时间顺序，重叠运行不合格，必须严格交替
每边不足 5 次完整结果、包含缺失结果、或数值范围重叠时只给 inconclusive
不同状态分别统计，不能把迷你窗口和托盘混成一组
不同构建即使显示方向性差异，也不能证明是轻量化的因果收益
没有等价基线时不做优化已生效的结论；本次不要求准备或运行完整矩阵
